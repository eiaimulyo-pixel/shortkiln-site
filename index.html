How it works

  1. Topic research — find subjects and formats worth making.
  2. Script — story order, opening hook and captions text.
  3. Edit — cuts, captions, color grading and rendering, driven by code.
  4. QA gates — automated checks; a video that fails any gate goes back to editing.
  5. Delivery — the finished file plus upload-ready title and description.

How we use Claude

  • Claude Code writes and maintains the pipeline. The renderers, checkers and delivery scripts are code that Claude Code writes, debugs and changes as the rules change.
  • Agents for planning and review. Separate Claude agents handle research and planning, and a second agent is used to challenge important design decisions before they are adopted.
  • Automated quality gates before delivery. Examples of checks that exist in our pipeline today:
    • Shorts UI occlusion check — on-screen text must not sit under the YouTube Shorts buttons, title or channel bar.
    • Silence check — no pause longer than 0.8 seconds; first spoken word within 0.3 seconds.
    • Color grading — every video goes through the channel's grading preset.
    • Blocked-content check — blocked sources and topics are rejected before delivery.
    • Content-credential (C2PA) signing of the final file.
