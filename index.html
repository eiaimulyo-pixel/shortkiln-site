How it works

One pipeline, from topic to upload-ready file.

Each stage is code that Claude Code writes and maintains. A video moves forward only when it passes the gates.

01

Topic

Find subjects and formats worth making.

02

Script

Story order, opening hook and caption text.

03

Edit

Cuts, captions, color grading and rendering, driven by code.

04

QA gates

Automated checks. Any failure sends the video back to editing.

05

Delivery

The finished file plus upload-ready title and description.

A failed gate loops back to Edit — fix, re-render, re-check.

How we use Claude

Claude Code is the production team.

The studio runs on code and agents rather than headcount.

Writes and maintains the pipeline

Renderers, checkers and delivery scripts are code that Claude Code writes, debugs and changes as the rules change.

Agents for research and planning

Separate Claude agents handle topic research and planning, so the main session stays focused on production.

A second agent challenges big decisions

Important design choices are drafted by one model and challenged by another before they are adopted.

Quality gates run before every delivery
  • Shorts UI occlusionOn-screen text never sits under the Shorts buttons, title or channel bar.
  • SilenceNo pause longer than 0.8 s; first spoken word within 0.3 s.
  • Color gradingEvery video goes through the channel's grading preset.
  • Blocked contentBlocked sources and topics are rejected before delivery.
  • Content credentialsThe final file is signed with C2PA.
A video that fails any gate is not delivered.

Formats

One pipeline, many shows.

Each format has its own spec, rules and gates. A few of the formats we have produced:

News commentary shorts

Political news explained in under a minute, with a clear opinion line and on-screen sources.

Celebrity moment montages

Face-tracked edits of a single moment, rendered in Korean, English and Japanese versions.

Military & aviation explainers

Aircraft and naval history told in short, caption-led clips.

Nature compilations

Wordless clips of ice, water and aurora, with the original creators credited on screen.

Joseon folk tales

Long-form storytelling with AI-generated illustrations and a single narrated voice.

Profile long-form

Life stories of public figures with a year chip and progress bar template.
